##About
  - Analysis of banknote dimensions across 42 currencies using Python. The dataset includes length and width measurements for different denominations, allowing us to explore how consistent banknote sizes are across currencies.

##Key Findings
  - 45.2% of currencies have banknotes where both length and width vary across denominations

  - 33.3% have only width constant (length varies)

  - 21.4% have identical dimensions for all banknotes

  - 0% have only length constant (width varies)

##Tools Used
 - Pandas – data manipulation and aggregation

Matplotlib – visualizations
